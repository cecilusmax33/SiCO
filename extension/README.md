# Installation Guide

To install the extension, follow the steps below:

1. Clone the repository:
   ```bash
   git clone https://github.com/cecilusmax33/SiCO.git
   ```
2. Navigate into the project directory:
   ```bash
   cd SiCO
   ```
3. Install dependencies:
   ```bash
   npm install
   ```

# Launch Guide

To launch the extension, follow these instructions:

1. Start the application:
   ```bash
   npm start
   ```
2. Open your browser and navigate to `http://localhost:3000` to access the extension.
